# Mathematics

Worksheets for *AIML Foundations Mathematics* (Dublin and Dún Laoghaire ETB), kept here as source material.

- `markdown/` holds the worksheets themselves, one markdown file each, most ending in an answer key. Worksheet 2B also exists as a Jupyter notebook and as a marimo script.
- `pdfs/worksheets/`, `pdfs/solutions/` and `pdfs/annotated/` hold the printable versions, the worked solutions, and annotated copies where they exist.

## Status: archive

This repository is no longer where new material is written. The worksheets with answer keys have been converted into practice pages in the `dewlab` repository, which is where tutorials and practice now live; `planning/EXERCISES.md` there records which worksheet fed which page. The PDFs remain the handout shelf for the AIML Foundations class and are linked from the course site. Correct a mistake here if you find one, but write anything new in dewlab.
